# Matplotlib Fundamentals

Task 28 - VEDA Technology Data Science Internship

## Project Description
This project demonstrates basic data visualization using Python, Pandas, and Matplotlib.

## Charts Created
- **Line chart:** Displays student marks.
- **Bar chart:** Compares marks across students.
- **Scatter plot:** Explores the relationship between study hours and marks.
- **Histogram:** Shows the distribution of student marks.

## Tools Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Key Learning
Learned to create charts with suitable titles and axis labels and interpret visual patterns in data.
